10 大網站介面設計特色

UI / UX Website Interface Examples
01

電商購物型

E-commerce
商品網格 + 分類導覽 + 搜尋 + 價格 + 購物車 + CTA
代表網站：UNIQLO
https://www.uniqlo.com/vn/vi/
適合學習：商品卡片、分類選單、促銷 Banner、購物流程。
02

品牌形象型

Brand / Landing Page
大圖主視覺 + 短標題 + 品牌色 + CTA + 大量留白
代表網站：CHANEL
https://www.chanel.com/vn/
適合學習：Hero Section、品牌一致性、圖片與文字比例。
03

社群動態型

Social Feed
動態牆 + 圖片／影片卡片 + 按讚 + 留言 + 分享
代表網站：Instagram
https://www.instagram.com/
適合學習：Feed、Card Design、互動 Icon、內容優先介面。
04

單一任務工具型

Utility / Single-task Tool
一個主要任務 + 大型操作按鈕 + 上傳／輸入 + 結果
代表網站：Remove.bg
https://www.remove.bg/
適合學習：明確 CTA、操作流程、Before / After。
05

線上工作區型

Workspace / Editor
工具列 + 左側功能區 + 中央畫布 + 編輯控制
代表網站：Canva
https://www.canva.com/
適合學習：Dashboard、Sidebar、Toolbar、Canvas Layout。
06

資訊／百科型

Information / Encyclopedia
大量文字 + 目錄 + 內文連結 + 清楚資訊層級
代表網站：Wikipedia
https://vi.wikipedia.org/wiki/Wikipedia
適合學習：資訊架構、閱讀性、標題階層、內容導覽。
07

搜尋／學習工具型

Search / Learning Tool
大型搜尋框 + 搜尋結果 + 字詞資訊 + 分類內容
代表網站：Hanzii
https://hanzii.net/?hl=vi
適合學習：Search-first UI、結果頁面、資訊階層。
08

影音娛樂型

Media / Entertainment
封面圖片 + 內容推薦 + 播放控制 + 個人化內容
代表網站：Spotify
https://open.spotify.com/intl-vi
適合學習：媒體卡片、播放列、Sidebar、推薦內容。
09

訂票／服務流程型

Booking / Service
選擇內容 + 日期／時間 + 確認 + 訂票／下單 CTA
代表網站：CGV Vietnam
https://www.cgv.vn/
適合學習：User Flow、步驟式操作、篩選與確認。
10

官方／學校入口型

Institutional / Portal
多層選單 + 公告 + 單位資訊 + 常用連結 + Footer
代表網站：嘉南藥理大學
https://www.cnu.edu.tw/en/index.asp
適合學習：Navigation、網站架構、不同使用者資訊入口。
