10 đặc trưng giao diện website phổ biến

Ví dụ giao diện UI / UX cho sinh viên
01

Website thương mại điện tử

E-commerce
Lưới sản phẩm + điều hướng danh mục + tìm kiếm + giá + giỏ hàng + CTA
Website tham khảo: UNIQLO
https://www.uniqlo.com/vn/vi/
Nên quan sát: thẻ sản phẩm, menu danh mục, banner khuyến mãi và quy trình mua hàng.
02

Website xây dựng hình ảnh thương hiệu

Brand / Landing Page
Hình ảnh lớn + tiêu đề ngắn + màu thương hiệu + CTA + nhiều khoảng trắng
Website tham khảo: CHANEL
https://www.chanel.com/vn/
Nên quan sát: Hero Section, tính nhất quán thương hiệu và tỷ lệ giữa hình ảnh với văn bản.
03

Website mạng xã hội dạng Feed

Social Feed
Dòng nội dung + thẻ hình ảnh/video + thích + bình luận + chia sẻ
Website tham khảo: Instagram
https://www.instagram.com/
Nên quan sát: Feed, thiết kế card, biểu tượng tương tác và cách ưu tiên nội dung.
04

Website công cụ một nhiệm vụ

Utility / Single-task Tool
Một nhiệm vụ chính + nút thao tác lớn + tải lên/nhập dữ liệu + kết quả
Website tham khảo: Remove.bg
https://www.remove.bg/
Nên quan sát: CTA rõ ràng, quy trình thao tác đơn giản và Before / After.
05

Website dạng không gian làm việc trực tuyến

Workspace / Editor
Thanh công cụ + khu chức năng bên trái + vùng làm việc trung tâm + điều khiển chỉnh sửa
Website tham khảo: Canva
https://www.canva.com/
Nên quan sát: Dashboard, Sidebar, Toolbar và bố cục Canvas.
06

Website thông tin / bách khoa

Information / Encyclopedia
Nhiều văn bản + mục lục + liên kết nội dung + phân cấp thông tin rõ ràng
Website tham khảo: Wikipedia
https://vi.wikipedia.org/wiki/Wikipedia
Nên quan sát: kiến trúc thông tin, khả năng đọc, cấp bậc tiêu đề và điều hướng nội dung.
07

Website tìm kiếm / học tập

Search / Learning Tool
Ô tìm kiếm lớn + kết quả tìm kiếm + thông tin từ vựng + nội dung được phân loại
Website tham khảo: Hanzii
https://hanzii.net/?hl=vi
Nên quan sát: Search-first UI, trang kết quả và cách phân cấp thông tin.
08

Website âm nhạc / giải trí

Media / Entertainment
Ảnh bìa + nội dung đề xuất + điều khiển phát + nội dung cá nhân hóa
Website tham khảo: Spotify
https://open.spotify.com/intl-vi
Nên quan sát: thẻ nội dung, thanh phát nhạc, Sidebar và khu vực đề xuất.
09

Website đặt vé / quy trình dịch vụ

Booking / Service
Chọn nội dung + ngày/giờ + xác nhận + nút đặt vé/đặt dịch vụ
Website tham khảo: CGV Vietnam
https://www.cgv.vn/
Nên quan sát: User Flow, thao tác theo từng bước, bộ lọc và bước xác nhận.
10

Website chính thức / cổng thông tin trường học

Institutional / Portal
Menu nhiều cấp + thông báo + thông tin đơn vị + liên kết nhanh + Footer
Website tham khảo: Chia Nan University of Pharmacy and Science
https://www.cnu.edu.tw/en/index.asp
Nên quan sát: Navigation, cấu trúc website và cách tổ chức thông tin cho nhiều nhóm người dùng.
